# 个人学习平台设计

## 产品方向

一个把个人学习、阅读、笔记、复习和日程放在一起的学习空间。Agent 可以负责创建和整理学习内容；平台负责把内容呈现成清晰、舒服、容易继续的体验。

## 设计原则

- 视觉采用苹果简约风：克制的颜色、柔和层次、充足留白和清晰文字。
- 一本 AI 生成的课程对应书架中的一本书；课程中的 Markdown 文档组成章节。
- 书架优先展示封面、课程名称、章节数量、阅读进度和继续阅读入口。
- 阅读页保持专注，支持目录导航、章节切换、阅读位置与进度、标记和舒适排版。
- 日历统一呈现学习时段与生活、工作日程；第一阶段不接第三方日历同步。
- 桌面端优先，同时适配手机屏幕。

## 页面与关键体验

### 今天

显示继续阅读、本周学习节奏、今日学习安排、日常事项，以及最近学习的书籍。学习时段可以和书籍、章节关联。

### 书架

以阅读应用的封面卡片展示课程书籍。支持分类浏览和搜索，并能一眼看到每本书的阅读进度。

### 阅读

从书架或今日页进入课程书。左侧目录对应 Markdown 章节，阅读区采用舒适行宽，显示阅读进度、章节导航、代码块和提示内容。

### 日历

以周历呈现学习安排和日常约会，并预留创建、编辑与关联学习内容的操作。

### 笔记与复习

笔记保留来源书籍和章节信息；复习聚合到期内容并提供轻量学习入口。

## 内容与数据流

课程资料由 Agent 创建和维护。平台的内容模型至少需要书籍、章节、阅读位置、笔记和日程之间的关联。Markdown 文件作为章节内容来源，章节顺序需要稳定，并允许书名、目录和章节内容更新。

前端页面通过明确的内容接口读取书籍与章节；读取失败时应保留上下文并提供可理解的重试入口。阅读位置与用户操作应独立保存，避免章节内容更新导致进度丢失。

## 第一阶段范围

先完成 Vue 3 前端视觉基础：今天、书架、阅读、日历、笔记和复习页面，以及页面间的基本导航。当前展示数据用于视觉原型；Agent 内容管理、持久化、文件导入和日程编辑后续再实现。

## 后续 Agent 工作边界

- 内容管理：定义 Agent 创建、更新、排序和删除书籍及 Markdown 章节的稳定接口。
- 阅读能力：持久化章节位置、书签、阅读进度和章节切换。
- 日历能力：实现日程创建、编辑、分类、重复规则和学习内容关联。
- 笔记与复习：保存来源关联，并按复习计划整理内容。

各功能通过独立页面或组件接入，避免多个 Agent 同时修改应用外壳和全局样式。
