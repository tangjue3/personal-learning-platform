# 本机个人学习平台与课程仓库方案

## 产品目标

把 Vue 3 原型逐步完善为当前电脑可日常使用的个人学习平台。课程 Markdown 由 Git 仓库管理；日程、待办、笔记、复习记录和阅读状态只保存在本机，不上传 GitHub。

主要学习流程：Agent 在仓库中维护课程 Markdown；平台将每个课程文件夹显示为一本书；用户阅读章节、保存进度和书签、记录笔记、制作复习卡，并安排学习日程。

## 已确认的产品选择

- 桌面端优先，保留 Vue 3 界面。
- 目前只在当前电脑运行，第二台电脑方案暂缓。
- 不设置私人数据口令，不加密个人学习数据。
- 个人学习数据保存到本机 `data/local/records.json`，由 `.gitignore` 排除。
- GitHub 仓库只管理课程书籍 `content/books/`；个人学习数据不会进入同步范围。
- 仓库如为公开仓库，课程 Markdown 和图片对所有人可见。
- Agent 通过稳定的 Markdown 与 `book.json` 约定管理课程。

## 数据边界

### 仓库课程

课程文件放在 `content/books/<book-id>/`，包含 `book.json`、Markdown 章节和公开课程图片。书籍文件会随 Git 仓库管理；课程同步接口只处理 `content/books/`。

### 本机个人数据

日程、待办、笔记、复习卡、阅读进度、章节位置、书签和偏好保存在 `data/local/records.json`。该目录被 Git 忽略，平台 Git 同步也不会暂存该目录。文件以普通 JSON 保存在本机，不加密。清理项目或迁移到另一台电脑前，需要用户自行复制备份。

旧版 `data/private/` 保留在 Git 忽略规则中，避免遗留文件误上传。应用不再读取旧的加密数据仓库。

## 应用架构

```text
Vue 3 本机界面
       │ 回环地址 API
       ▼
本机 Node 服务
       ├── 课程书籍：content/books/（Git 管理，可同步）
       ├── 个人记录：data/local/records.json（Git 忽略）
       └── Git 同步：仅 content/books/
```

- 服务只绑定本机回环地址，不作为局域网或公网服务开放。
- 浏览器通过本机 API 读写课程与个人数据。
- GitHub 凭据交由系统 Git 凭据管理器处理。
- 个人数据不通过应用接口或 Git 同步上传。

## 课程同步

1. 本机自动保存课程书籍变更。
2. 用户在应用中点击“同步课程到 GitHub”。
3. 本机仅暂存 `content/books/`，拉取远端课程，再推送课程更新。
4. 课程文件发生冲突时保留本机提交并提示处理方式。
5. 网络中断或 Git 操作失败时，保留本机课程和个人数据。

## Agent 工作约定

- Agent 可以读写 `content/books/` 中的课程信息和章节。
- Agent 不应访问、整理或同步 `data/local/` 中的个人记录。
- 书籍 ID 和章节路径保持稳定，便于阅读位置继续关联。
- 章节按路径自然排序；保留相对 Markdown 链接。Markdown 一级标题作为章节标题。
- Agent 更新课程后，平台重新加载书架即可显示变更。

## 功能完善顺序

### 课程与阅读

- 完善文件夹导入、重复课程更新和内容变更提示。
- 支持常用 Markdown 语法、代码块、图片和章节内跳转。
- 稳定保存阅读进度、最近位置、书签和逐章完成状态。

### 日程与个人记录

- 完善日历、待办、笔记和复习卡片的新增、编辑、删除和搜索。
- 保证本机文件写入稳定，增加本机备份与恢复流程；恢复只新增无冲突记录，使用原子写入避免部分导入。
- 增加易懂的本地数据文件位置和迁移说明。

### 日常可用性

- 完善首次启动、数据服务离线、文件损坏和课程同步错误的提示。
- 提供稳定的本地启动入口；平台基础流程成熟后，再考虑桌面安装程序。

## 完成标准

- 重启平台后，本机课程和个人记录均能恢复。
- GitHub 同步仅包含课程书籍，不包含个人学习数据。
- 个人记录的新增、编辑和删除能在本机可靠保存。
- Agent 按课程约定更新 Markdown 后，书架能显示变更。
