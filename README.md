# 知序 · 个人学习空间

基于 Vue 3 和 Vite 的个人学习平台前端原型，采用简洁的 Apple 风格界面。

## 功能页面

- 今天：学习概览、近期阅读和待办事项
- 书架：按类别浏览书籍，把一门课程中的多篇 Markdown 文档导入为一本书
- 阅读器：章节目录、阅读进度、书签和阅读外观设置
- 日历：周视图和月视图，管理学习与生活日程
- 笔记与复习：个人学习记录和复习入口

导入的书籍存储在浏览器 IndexedDB 中；阅读位置和书签保存在本地浏览器。日历当前使用演示数据。

## 本地运行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

生成生产版本：

```bash
npm run build
```

## 技术栈

- Vue 3
- Vite
- 原生 CSS
