# 第 1 章 · RAG 概览

检索增强生成（Retrieval-Augmented Generation，RAG）先从外部知识中找到与问题相关的内容，再把这些内容交给大语言模型生成回答。

## 为什么需要 RAG

模型参数中包含的知识有边界，也不一定覆盖最新资料。RAG 让回答能够引用一组可管理的文档，并能随着资料更新而更新。

一个基础的 RAG 应用通常包含三个步骤：

1. **准备知识**：读取文档、切分文本，并为每个片段建立索引。
2. **检索上下文**：根据用户问题找到相关片段，必要时进行重排。
3. **生成回答**：将问题与检索结果一起提交给模型，并按需要附上来源。

## 核心数据流

```text
文档 → 清洗与切分 → 索引
                     ↓
用户问题 → 检索与重排 → 上下文 → 大语言模型 → 回答
```

RAG 的质量取决于整条链路。检索到的内容不相关时，即使提示词写得很好，模型也很难给出可靠回答。

## 本章要点

- RAG 把外部知识接入模型的生成过程。
- 离线索引和在线问答是两条互相配合的流程。
- 排查问题时，要分别观察检索结果和最终回答。
