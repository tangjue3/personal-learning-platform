# 仓库课程书籍

把课程 Markdown 放在这个目录中，书架会自动将每个课程文件夹识别为一本书。

课程书籍由 Git 仓库管理并可同步到 GitHub。当前仓库为公开仓库，放入此处并提交的课程内容也会公开。请勿把私人笔记、个人安排或其他不希望公开的内容放入课程目录。

## 目录格式

```text
content/books/
  course-id/
    book.json
    01-课程概览.md
    02-核心内容.md
    03-实践练习.md
```

课程目录中的 Markdown 文件会按文件路径自然排序并作为章节显示。建议用 `01-`、`02-` 这样的前缀标出阅读顺序；章节标题优先读取 Markdown 的一级标题 `# 标题`，没有一级标题时使用文件名。

`book.json` 示例：

```json
{
  "id": "course-id",
  "title": "课程名称",
  "coverTitle": "封面标题",
  "subtitle": "课程副标题",
  "category": "人工智能",
  "theme": "blue"
}
```

- `id` 在所有课程中保持唯一，创建后不要随意修改，这样阅读进度才能继续关联到同一本书。
- `title` 必填；`coverTitle`、`subtitle` 可选。
- `category` 可选：`技术`、`人工智能`、`产品设计`、`通用能力`。
- `theme` 可选：`blue`、`sand`、`night`、`sky`、`peach`、`mist`、`forest`。
- 章节文件可以放在课程目录的子文件夹中，也会被收集。

在课程目录中新增、修改或删除 Markdown 文件后，开发预览会跟随仓库文件更新；同步课程时只处理本目录中的课程书籍。
